Project Title: Customer Segmentation Analysis using RFM Analysis and K-Means Clustering
Dataset: Customer_dataset.csv
1. Project Objective
The objective of this project was to perform customer segmentation using RFM (Recency, Frequency, Monetary) analysis and the K-Means clustering algorithm. Customer segmentation helps businesses understand customer purchasing behavior, identify high-value customers, and develop targeted marketing strategies.
2. Dataset Overview
The dataset contains customer transaction records collected during the year 2023.
Dataset Summary
* Total Transactions: 50,000
* Total Customers: 50,000
* Total Features: 9
* Transaction Period: January 2023 Ð September 2023
* Categories: 6
* Merchants: 36,939
The dataset includes customer information, transaction amount, transaction date, merchant name, and product category.
3. Data Cleaning
The following preprocessing steps were performed before analysis:
* Successfully loaded the dataset using Pandas.
* Checked for missing values.
* Identified 5,047 missing values in the Gender column.
* Verified that there were no duplicate records.
* Converted the Date column into DateTime format.
* Generated a TransactionID column for RFM analysis.
The dataset was successfully prepared for customer segmentation.

RFM Analysis was performed using the following metrics:
* Recency (R): Number of days since the customer's last transaction.
* Frequency (F): Number of transactions made by each customer.
* Monetary (M): Total amount spent by each customer.

9. Business Recommendations
Based on the clustering results, the following recommendations are proposed:
* Reward VIP customers with exclusive discounts, premium memberships, and loyalty programs.
* Maintain engagement with Loyal customers through personalized offers and reward points.
* Encourage Regular customers to purchase more frequently using targeted promotions and cross-selling strategies.
* Re-engage At Risk customers through email campaigns, special discounts, and reminder notifications.
* Utilize customer segmentation to personalize marketing campaigns and improve customer retention.

* The segmentation results provide valuable information for customer retention, marketing, and sales strategies.
